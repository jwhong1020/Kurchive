# 커카이브 프로젝트
<b>기간</b>
2025.08 ~ 2026.07 Ongoing



# 목적
1) 동아리 구성원들이 축적한 맛집 정보를 체계적으로 보존하고, 검색 및 공유할 수 있는 아카이빙 플랫폼을 구축하여 지식의 단절을 방지하는 것을 목표로 함.
2) 동아리 내 분산되어 있던 레시피 정보를 하나의 플랫폼으로 통합하고, 축제 기간 및 엠티 기간마다 직면했던 단위 변환 문제를 자동 계산으로 해결하기 위함.
